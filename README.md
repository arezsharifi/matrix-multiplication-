# matrix-multiplication-
# Python Practice

A small collection of Python exercises I wrote while learning. Each file is
self-contained and focuses on one concept.

## Contents

| File | What it does | Concepts practiced |
|------|--------------|--------------------|
| `matrix_multiplication.py` | Multiplies two hard-coded matrices `a` (2×3) and `b` (3×4) and prints the result | Nested lists, nested loops, matrix math |
| `bracket_balance.py` | (Work in progress) Checks whether brackets in a string are balanced — `()`, `[]`, `{}` | Loops, lists as stacks, conditionals |

## Running

No dependencies beyond the Python standard library. Tested with Python 3.

```bash
python matrix_multiplication.py
python bracket_balance.py
